# Coconut Leaf Disease Image Classification Agent App

An Android app using a TensorFlow Lite machine learning model trained for coconut leaf disease image classification.

## Recommendations

- Update the TFLite model for better accuracy. Use a larger and more precise training image dataset.
  
- Provide more relevant information about the different coconut leaf diseases being classified.
